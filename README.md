# Rockfall Prevention and Worker Safety System

## Overview

This project is an AI-powered rockfall prevention and worker safety system designed for open-pit mining environments. The system aims to detect high-risk rockfall zones using drone image analysis and provide safety alerts to workers to reduce accidents and improve mine safety.

This project was developed as part of a technical innovation/hackathon idea focused on improving worker protection in mining operations.

---

## Features

- Drone image-based rockfall risk detection
- AI/ML-powered hazard analysis
- High-risk zone identification
- Worker safety alert mechanism
- Twilio SMS notification integration
- Flutter-based frontend application
- Python backend services
- Real-time monitoring architecture
- Scalable system design for mining environments

## Installation

### Clone Repository

```bash
git clone https://github.com/ajaikumar18/rockfall_prevention_app.git
```

### Move into Project

```bash
cd rockfall_prevention_app
```

### Install Flutter Dependencies

```bash
flutter pub get
```

### Install Python Dependencies

```bash
pip install -r requirements.txt
```

### Run Flutter Application

```bash
flutter run
```

### Run Backend

```bash
python app.py
```
